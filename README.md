# Chronos Adventure VR

**Chronos Adventure VR** is a Unity-based project that takes the player on an immersive VR adventure, combining exploration, activities, and interactive storytelling.
The virtual setting presents the reconstruction of an ancient Greek polis in the low poly style, with three different thematic areas: culture, daily life and mythology.

---

## 🚀 Key Features
- Immersive **VR** experience built with Unity.
- Interactive system for objects and environments.
- Custom asset management (`MyAsset`) integrated into the project.
- Modular architecture designed for easy gameplay expansion.

---

## 📂 Project Structure
The repository includes the essential folders required for Unity projects:
- `Assets/` → contains game resources (models, textures, scripts, **MyAsset**).
- `Packages/` → Unity dependencies and packages.
- `ProjectSettings/` → Unity project configuration files.

---

## 🔧 Requirements
- **Unity** (recommended version: 2021.3 LTS or newer).
- Meta SDK.
- Git for version control.

---

## ▶️ Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/emanueleivn/ChronosAdventureVR.git
2. Open the project in Unity Hub.
3. Select your target VR platform and build the project.
